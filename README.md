# queenannemagnoliadispatch.com

Static landing site for the Queen Anne & Magnolia Dispatch newsletter (GitHub Pages). Generated by `site/dispatch/build.py queenannemagnolia` in the ai-ops repo. Edit there, rebuild, push here. The signup form posts to the n8n webhook `queenannemagnolia-dispatch-signup`, which creates the beehiiv subscription with custom fields; beehiiv → n8n → Follow Up Boss.
